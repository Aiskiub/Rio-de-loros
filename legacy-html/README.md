# Café Río de Loros

Página de presentación con pedidos por WhatsApp. HTML, CSS y JavaScript sin proceso de compilación; la animación usa GSAP desde un CDN.

## Ver en local
Abre `index.html` en el navegador, o sirve la carpeta con cualquier servidor estático.

## Qué editar
- **Número de WhatsApp:** busca `573214976785` en `index.html` (tres veces: dos en los scripts y una en el pie de página).
- **Productos, textos y colores por slide:** arreglo `SLIDES` en el primer `<script>`.
- **Fotos de "Nosotros":** reemplaza los archivos de `assets/fotos/` conservando el nombre (`jhonattan.webp`, `finca-1.webp`, `finca-2.webp`).
- **Empaques y granos:** `assets/`, en WebP con fondo transparente.

## Publicar
Funciona en Vercel, Netlify o GitHub Pages sin configuración: apunta al directorio raíz del repositorio.
